# Superseded ADRs

This folder holds **retired** architecture decision records that are replaced by a newer ADR in the parent [`docs/adrs/`](../) directory. Files are kept **in full** for history; the **canonical** contract is always the newer document referenced in each file’s header and in the replacement ADR’s **Supersedes** row.

Do not add new first-class ADRs here—publish new decisions under `docs/adrs/` and move the old file here only when explicitly superseded.
